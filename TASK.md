1. Создать viewer для максимального количества типов файлов
2. Язык: Python/PyQt
3. Список необходимых пакетов для pip (requirements.txt) для установки на чистой ubuntu
4. Функционал:
Две панели: справа дерево файлов, слева окно для просмотра содержимого (так или иначе).
Поддерживается сортировка файлов по дате, имени, типу
Чем больше типов файлов поддерживается, тем лучше: txt, doc/docx, jpeg, png, avi, etc...
Просмотр не должен использовать сторонние приложения, все должно быть решено программно
5. Выложить на гитхаб вместе с видео работы
6. По желанию: документировать через doxygen
