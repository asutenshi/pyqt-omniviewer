# demo/

Фиксированный набор образцов файлов для ручной демонстрации и смоук-тестов
(`ViewerRegistry` прогоняется по этому каталогу, а не по случайным файлам
системы).

## Генерация

```bash
python demo/generate.py
```

Идемпотентно: повторный запуск не меняет уже созданные файлы. Скрипт использует
только стандартную библиотеку. См. `demo/generate.py` — что именно создаётся
(тексты, исходники, `csv`/`tsv`, `json`/`yaml`/`xml`/`ini`, простые `png`/`jpeg`,
большой текстовый файл сверх порога оконного чтения, набор «битых» обрезанных
образцов, файл без расширения с распознаваемым содержимым).

## Правила

- Происхождение и лицензии бинарных образцов — `demo/CREDITS.md`
  (только CC0 / public domain).
- Суммарный размер `demo/` — строго меньше 5 МБ.
- Каждый тикет-просмотрщик добавляет сюда свой образец и, при необходимости,
  ветку в `demo/generate.py`.
